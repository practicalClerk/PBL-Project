Welcome to AI Fraud Detection

Our platform uses Artificial Intelligence to safeguard users from fraudulent activities online. From detecting phishing websites to analyzing fake job postings and identifying deepfake content, we aim to provide a secure online experience.

Current Features

  • ✅ Phishing Website Detector - Checks if a website is legitimate or a scam.
  • ✅ AI Document Detector - Scans uploaded file and check whether AI generated or not.
  • ✅ Research Helper/Detector - Helps Researchers with their research work and detects Plagrism.

✅ New Release (POST MTE)

  • 🛡️ Phishing Detection Model Integrated with JSON Dataset – Verifies website URLs against a known phishing list.
  • 📄 AI Document Detection Model (TXT Supported) – Uploads and analyzes .txt files using a rule-based system to detect AI-written patterns.
  • 📦 Prototype-Only Approach – Avoids Flask for AI document detection model; kept lightweight for demonstration and understanding.
  • 🌐 Manual JSON + MySQL Hybrid – JSON used for phishing URLs; MySQL used for new unknown entries + trust scoring.

Future Plans

  • 🚀 Machine Learning Integration to automatically classify new unknown URLs as phishing or not.
  • 🚀 Database to store New URL's .
  • 🚀 Real-time Trust Scoring System for each user-submitted URL using crowd-based feedback.
  • 🚀 User Feedback Mechanism to improve detection accuracy and user trust.
  • 🚀 Integration of PDF & DOCX Analysis for AI-generated document detection.
  • 🚀 URL Submission via Link Upload (Coming Soon) for users to submit document links instead of files.
  • 🚀 Exportable Detection Report for users to download results and share evidence.
