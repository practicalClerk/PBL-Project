## 🚀 How to Run

### Local Development:
```bash
cd Backend
pip install -r requirements.txt
python train_model.py
python app.py
```
**Access:** http://localhost:5000

### Docker Deployment:
```bash
cd Backend
docker build -t phishing-detector .
docker run -d -p 5000:5000 phishing-detector
```
**Access:** http://localhost:5000
